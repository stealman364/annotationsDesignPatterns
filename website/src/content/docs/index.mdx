Patrones de diseño, resiliencia y caché para TypeScript, con decoradores
estándar TC39 o funciones componibles. Cero dependencias de ejecución,
tipado estricto e importaciones granulares.

```sh
npm install annotations-design-patterns
```

Esta documentación corresponde a **2.3.0**. La guía de migración identifica
las novedades y las APIs que conservan su estado experimental.

## Con decoradores

```ts
import { Singleton, Retry, Timeout, Fallback } from 'annotations-design-patterns';

@Singleton
class ApiClient {
  @Fallback<User[]>([])
  @Retry({ attempts: 3, delayMs: 200, backoffFactor: 2 })
  @Timeout(5000)
  async fetchUsers(): Promise<User[]> {
    /* ... */
  }
}
```

## Con funciones

```ts
import { fallback, retry, timeout } from 'annotations-design-patterns/operators';
import { pipe } from 'annotations-design-patterns/pipe';

const fetchUsers = pipe(
  loadUsers,
  fallback<object, readonly [], User[]>([]),
  retry({ attempts: 3, delayMs: 200, backoffFactor: 2 }),
  timeout(5000),
);
```
