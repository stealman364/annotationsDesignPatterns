Design patterns, resilience and caching for TypeScript, with standard TC39
decorators or composable functions. Zero runtime dependencies, strict types
and granular imports.

```sh
npm install annotations-design-patterns
```

The stable release is **2.2.0**. These docs also cover **2.3.0-rc.1**;
the migration guide identifies new and experimental features.

## With decorators

```ts
import { Singleton, Retry, Timeout, Fallback } from 'annotations-design-patterns';

@Singleton
class ApiClient {
  @Fallback<User[]>([])
  @Retry({ attempts: 3, delayMs: 200, backoffFactor: 2 })
  @Timeout(5000)
  async fetchUsers(): Promise<User[]> {
    /* ... */
  }
}
```

## With functions

```ts
import { fallback, retry, timeout } from 'annotations-design-patterns/operators';
import { pipe } from 'annotations-design-patterns/pipe';

const fetchUsers = pipe(
  loadUsers,
  fallback<object, readonly [], User[]>([]),
  retry({ attempts: 3, delayMs: 200, backoffFactor: 2 }),
  timeout(5000),
);
```
