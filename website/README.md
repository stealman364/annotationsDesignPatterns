# Documentation website

Astro Starlight serves the Spanish and English guides. This private project has
its own lockfile and requires **Node 22.23.4 or newer**, independently of the
library's Node 20 requirement. From `website/`:

```sh
npm ci --ignore-scripts
npm run build
npm run preview
npm audit --json
```

The output is `dist/`, served at `/annotationsDesignPatterns/`. GitHub Pages CI
builds this directory and only deploys from the default branch. Local builds and
pull requests do not deploy. For editing guides, run `npm start`; API assets are
generated by `npm run build:api` (included in the full build).

## Content and compatibility

Edit Spanish guides in `docs/` and English guides in
`i18n/en/docusaurus-plugin-content-docs/current/`. That historical source location
is retained to preserve repository links; Docusaurus is no longer a dependency.
Every source page needs its translation. `prepare:content` generates Starlight
pages in ignored directories, adapting titles, sidebar ordering and links.
Do not edit generated pages. Public guide URLs retain `/docs/...` and
`/en/docs/...`; the locale selector links equivalent guide pages.

TypeDoc generates one shared English API at `/api/`, with its own symbol search
and links back to guides in both languages. Pagefind searches Starlight guides
in the selected language. Legacy API URLs in either locale redirect to their
corresponding module or symbol. `scripts/fixtures/legacy-api-routes.json` records
the old route inventory; the build fails if a destination cannot be resolved.
Guide heading anchors are checked against the old output. Generated API section
anchors can differ between renderers even though redirects forward incoming hashes.

`npm run verify` checks built local links, locales, guide inventory, Pagefind
indexes, public API modules and legacy aliases. External URLs are not checked.

## Private TypeDoc patch

TypeDoc 0.28.20 declares minimatch 10.x. This project pins an override to 11.0.5
and applies the reviewed local compatibility patch from the isolated trial.
The override alone breaks directory traversal (`matchOne` was removed).
`prepare:typedoc` adapts it using the public partial matcher with preserved
negation semantics. This is **not an upstream-supported dependency combination**.

There is no install hook. API generation and glob verification explicitly run
the patch, including after `npm ci --ignore-scripts`. Exact versions, local
installation and full source hashes are checked; unknown inputs fail without
writing. `npm run verify:typedoc` compares 26 real traversal cases against the
unmodified dependency baseline. Upgrades require reviewing or removing this
patch, preferably replacing it with an official compatible TypeDoc release.

See the [patch report](../release/audits/STARLIGHT-REDUCTION-RESULTS.md) and
[migration plan](../release/audits/STARLIGHT-MIGRATION-PLAN.md).
