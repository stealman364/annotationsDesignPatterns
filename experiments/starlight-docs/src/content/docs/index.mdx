## Dos formas de componer

Los decoradores expresan el comportamiento junto a un método. Las funciones
componibles permiten construir la misma cadena explícitamente cuando esa forma
encaja mejor con la aplicación.

```ts
const protectedCall = retry({ attempts: 3 })(withTimeout(500)(loadProfile));
```

El ensayo conserva el sitio bajo la ruta base de GitHub Pages y publica un
selector para leer el contenido equivalente en inglés.
