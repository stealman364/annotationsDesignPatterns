# v2.1 execution baseline

Date: 2026-10-28 (Europe/Madrid).

## Scope and status

Implementation is prepared locally as `2.1.0-rc.0` on branch
`fix/2.1-correctness-rc`, based on `91f1142`. No package was published and no
stable release or Git tag was created.

The original audit B1-B16 attachments never became available. After the user
instructed implementation to continue, reproduction tests were independently
reconstructed from the execution plan. Their current-bug assertions passed,
then correct assertions failed before the fixes. These tests are not presented
as the missing audit originals. B17-B19 remain deferred reading findings:
StateMachine async races, cache growth, and wall-clock behavior.

All required runtime waves and type work are implemented. Optional `isFailure`,
`maxDelayMs`, jitter and other 2.2 features were omitted. `keyedLock` keeps its
existing queue implementation; only its numeric validation and caller-visible
cancellation contract changed.

## Characterization contracts

New tests in `tests/characterization/v2-event-contracts.test.ts` freeze:

- `overlap(drop)`: started, dropped, completed, correlated to the proper caller.
- `overlap(share)`: only the initiating execution emits started/completed.
- `overlap(queue)`: started, queued, completed, started, completed in order.
- Event key, operator and metadata for all three overlap modes.
- `keyedLock`: withdrawing a queued caller emits no acquisition or release for
  that caller, frees queue capacity, and preserves subsequent event order.
- CircuitBreaker: CLOSED success is silent; OPEN rejects silently; a failed
  HALF_OPEN probe emits half_open/open; a successful probe emits half_open/closed.

New tests in `tests/characterization/v2-cache-contracts.test.ts` freeze:

- Default functional memoize and cachedFor caches are shared across receivers
  within one applied method.
- Functional `cachedFor(0)` disables caching.
- Functional `cachedFor(Infinity)` has no expiration.

Existing tests retained as additional contracts:

## Integrated decisions and regression evidence

| Wave | Implementation and verification |
| --- | --- |
| 1 | Domain numeric validation, computed Retry timer clamp, async Revertible, acronym builder and Subject snapshot. Gate: 544 tests, typecheck, lint, build and installed-package smoke passed. |
| 2 | Root-vs-execution cancellation provenance, exact caller reasons, isolated shared work, timeout context without sequence allocation, per-layer mixed composition, reusable global timeout policy. Cancellation matrix includes 80 scenarios and additional reentrancy tests. |
| 3 | Internal PermitQueue, overlap queue migration and Semaphore direct transfer. Deterministic 100-operation bursts cover cancellations, failures, capacity and FIFO. Gate: 669 tests plus typecheck/lint/package passed. |
| 4 | HALF_OPEN probe lease of resetMs and generation protection. Nine dedicated tests cover late resolve/reject, replacement failure/reset windows and cancellation ownership. Gate: 678 tests plus typecheck/lint/package passed. |
| 5 | On/Emits event/payload checks and When/TransitionTo closed-state validation; no runtime change in these type patches. Installed ESM and CJS declaration consumers verify positive and negative cases. |
| Engineering | Controlled per-file any budgets; 96 ESM/CJS entrypoint footprint budgets; critical-file coverage percentages and tighter global uncovered budgets; bilingual migration/changelog and packed RC fixtures. |

Architectural review kept Command undo synchronous; nested undo remains supported
without recursion or removing failed commands. Shared work has no reference-counted
cancellation. An opaque ordinary custom operator remains a boundary for inner
context; contextual outer layers, identities and nested pipelines retain it.
Applying plain operators per caller was rejected because it would reset state.

No new public runtime export, PolicyEvent kind, runtime dependency, or default
cache scope/key strategy was introduced. Functional cache TTL still starts at
invocation; successful detached work can populate the cache even when one caller
stops waiting. Errors retain their existing classes and policy paths.
