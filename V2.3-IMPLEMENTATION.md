# 2.3 implementation plan and contracts

Authorized locally on 2026-11-07. Preserve the existing working changes; no commit, push, tag or publication. This plan supersedes design-document statements that runtime implementation has not been authorized.

## Compatibility decisions

- Preserve default sync results, throws, cache identity, TTL and policy unions. Add no runtime dependencies. New optional execution sharing uses a separate path.
- Functional rateLimit uses an exact sliding admission log, performance.now(), per-applied-method state and immediate rejected excess calls. Admission consumes quota even on failure. Keep the legacy decorator unchanged.
- memoize maxEntries reuses existing FIFO capacity, including pending values. Bounds apply per receiver/handle and are not physical execution bounds.
- executionMethod exposes readonly invocation data and effective signal through pipe/run. Direct calls have no contextual signal. Ordinary .apply() and opaque wrappers remain explicit context boundaries; no ambient context.
- Shared cancellation is opt-in and initially experimental. Each owner has its own root cancellation signal, preserved through timeout derivations. No-signal consumers remain until settlement. Last withdrawal retires lookup visibility by identity before abort dispatch; eviction/TTL/invalidation do not withdraw consumers. Sync initiators remain sync; reentrant joins use the reservation promise. Cyclic self-await is unsupported and documented.
- StateMachine reject-stale uses first-valid-commit semantics and identity revisions; same-state and manual/nested transitions invalidate pending work. The opt-in final commit is internal/nonvirtual, supporting subclasses whose manual transition overrides delegate to super. A frozen per-instance symbol companion holds closures over private fields so independently bundled entrypoints interoperate without a global instance registry. Legacy decorator completion still dispatches transitionTo virtually. Conflicts do not roll back effects or automatically retry.
- Counter/span adapters and sink composition are stable, isolate synchronous/accidental async callback failures, and select bounded built-in operator labels. observeOperation is experimental: one result per layer invocation, including a preabort that reaches the layer, fixed before callback; run's existing preabort gate can reject before any layer is invoked. Signal-origin cancellation is distinct from timeout and ordinary AbortError. It measures observable layer completion, not physical backend completion.
- External cache is experimental and always async, with explicit schema namespace, codec, store failure policy and mandatory finite I/O deadline. `bypass` tolerates all provider get/set failures (including permission/configuration errors); key/schema/codec failures still reject. Stop follow-up work after cancellation; do not start writes after it. In-flight reads and writes can finish late; deadlines bound waiting, not physical I/O. No distributed deduplication or stale-write guarantee.
- Experimental CAS uses opaque versions across absent/present states, expiry and deletion. The reference guarantees no version reuse within one store instance. Cross-instance/copy namespace identity uses Web Crypto when available and a collision-resistant, probabilistic fallback otherwise; tokens are scoped to their store. A memory reference and conformance tests establish local semantics only. No remote lock/breaker/semaphore guarantee without a real tested provider.
- Handles own state at the factory level, inspect without mutation, and never revoke permits. Breaker reset advances its generation, invalidating pending CLOSED work and probes. No global registries.
- Correct AsyncMemoryStore mutation ordering separately: per-key mutations serialize, clear acts as a mutation admission barrier, and new writes admitted after clear wait for it. Reads preserve the previous non-blocking committed-value behavior, including reads inside an updater. Updaters must not await same-key mutations or clear/cleanup (self-dependency); no universal reentrancy detection is claimed.
